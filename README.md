# Script-Hogar-con-Netflix
Script para "optimizar" Hogar con Netflix Restricción de IP
Optimizar a veces significa EVADIR.

# Instrucciones para hacer uso de este script

1._Abrir herramientas de desarrollador F12 o Ctrl+Shift+C
2._ir a la pestaña Red/Network
3._Subir hasta el principio y encontrar el script otSDKStub.js
4._Clic derecho y seleccionar Anular Contenido/Override
5._Aceptar los permisos y seleccionar una carpeta que debe mantenerse sin borrar.
6._Ir a la pestaña Fuentes/Override y ubicar el archivo otSDKStub, abrirlo y pegar en la ultima linea alguna de las funciones de los archivos .js


# Recomendaciones
La funcion del archivo OptionUsedByMe.js es la que uso yo en todo momento y por lo tanto, es actualizada constantemente. Esto garantiza su funcionalidad.

De preferir alguna otra funcion, Elegir a placer las del archivo Opcion_1.js y en caso de no funcionar, las de Opcion_2.js
